HTML parsed as browsers parse it (the HTML standard: tokenizer, tree construction, foreign content) and serialized, with no dependencies. Every declaration of its TypeScript declarations (packages/html/index.d.ts or index.d.cts), as they are written, with their comments: made from them each time the docs are built.
