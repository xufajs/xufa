From Django

@xufa/orm follows Django's ORM: models with fields, a manager (objects), lazy QuerySets that chain, lookups with __, Q and F, migrations made from the models. In JavaScript the names are camelCase and every query is awaited. This page is the map from one to the other; the same app on both, measured, is in xufa and Django.

The same queries

    name = models.CharField(max_length=100)

class Book(models.Model):
    title = models.CharField(max_length=200)
    pages = models.IntegerField(default=0)
    author = models.ForeignKey(Author, related_name="books", on_delete=models.CASCADE)

    class Meta:
        ordering = ["title"]

// @xufa/orm
import { Database, Model, fields, F, Count } from '@xufa/orm';

class Author extends Model {
  static fields = { name: fields.string({ maxLength: 100 }) };
}

class Book extends Model {
  static fields = {
    title: fields.string({ maxLength: 200 }),
    pages: fields.integer({ default: 0 }),
    author: fields.foreignKey(() => Author, { relatedName: 'books', onDelete: 'cascade' }),
  };

  static options = { ordering: ['title'] };
}

const db = new Database({ backend: 'sqlite', filename: ':memory:' });
db.register(Author, Book);
await db.connect();
await db.sync();
const ada = await Author.objects.create({ name: 'Ada' });
await Book.objects.create({ title: 'Engines', pages: 300, author: ada });

const books = await Book.objects
  .filter({ author__name__istartswith: 'a', pages__gte: 100 })
  .selectRelated('author')
  .limit(10);
const counts = await Author.objects.values('name').annotate({ books: Count('books') });
await Book.objects.filter({ pk: 1 }).update({ pages: F('pages').add(1) });
const [book, created] = await Book.objects.getOrCreate({ title: 'Notes' }, { pages: 10, author: ada });

console.log(books.map((b) => `${b.title} (${b.author.name})`), counts);
console.log(book.title, created, (await Book.objects.get({ pk: 1 })).pages);
await db.close();
[ 'Engines (Ada)' ] [ { name: 'Ada', books: 1 } ]
Notes true 301

Lookups

exact, iexact, contains, icontains, in, gt, gte, lt, lte, startswith, istartswith, endswith, iendswith, range, isnull, regex, iregex, as Django has them, across relations (author__name__icontains, and reverse ones: books__title) and inside json fields (meta__a__b). And like and ilike, with the patterns of SQL. And the parts of dates: __year and __date (ranges of the field), __month, __day, __week_day, __iso_week_day, __week, __quarter, __hour, __minute and __second, in UTC.

Signals

pre_save, post_save, pre_delete, post_delete are hooks of the model: Book.on('beforeSave' | 'afterSave' | 'beforeDelete' | 'afterDelete', fn). As in Django, bulkCreate and update of QuerySets do not run them.

Several databases

DATABASES and routers are Databases with routes (a model to a database); using() chooses one for a query. Tenants give each tenant a database of its own, chosen by the request (Tenants).

Everything is awaited

Every query is a promise: await Book.objects.filter(...) runs it (as Django's async for and aget() do), and a QuerySet that is not awaited sends nothing. Saving, deleting, loading a relation are awaited too.

Relations are loaded on purpose

Django loads a foreign key when it is first read, with a query each time (the N+1 queries of a loop). Here book.author is undefined until it is loaded: with selectRelated('author') (a join), prefetchRelated (one query for many objects) or await book.load('author'). The key is always there: book.authorId.

Not in @xufa/orm

  • Ordering and values across reverse relations (conditions and aggregates follow them).
  • Multi-table and proxy inheritance (abstract parents are there), generic relations (contenttypes).
  • Custom managers are written as scopes (static scopes = { published: (qs) => qs.filter(...) }: Post.objects.published()), and soft deletes are an option of the model (softDelete): see Scopes and soft deletes.
  • Forms: @xufa/openapi documents the routes, and resources give a model its routes (Resources). The admin is @xufa/admin, and the command line (migrations, generators, shell) is xufa.
