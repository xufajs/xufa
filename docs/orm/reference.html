Reference

The ORM of xufa: Django-like models and querysets over SQL and NoSQL databases, with no dependencies. Every declaration of its TypeScript declarations (packages/orm/index.d.ts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.
