Overview Reference

Reference

OpenAPI 3 and Swagger 2 documents of the routes of an app, with the API of @fastify/swagger and its tests, and an explorer; without dependencies but @xufa/yaml. Every declaration of its TypeScript declarations (packages/openapi/index.d.ts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.
