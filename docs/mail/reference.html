Overview Reference

Reference

Emails as classes (as Laravel's Mailables) rendered with templates in a layout for email clients, sent through the mail backends of @xufa/orm at once or from jobs of @xufa/queue, and notifications by mail, database or channels of your own, with no dependencies. Every declaration of its TypeScript declarations (packages/mail/index.d.ts or index.d.cts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.

Functions

mailFields, textOf, notificationFields

mailFields

export declare function mailFields(fields: any): Record<string, any>;

The fields of a model of emails: class Email extends Model { static fields = mailFields(fields); }.

textOf

export declare function textOf(html: string | null | undefined): string;

The text of the HTML of an email: blocks on lines, links with their addresses, lists, entities decoded.

notificationFields

export declare function notificationFields(fields: any): Record<string, any>;

The fields of the model of the notifications kept: notifiableType, notifiableId, type, data, readAt, createdAt.
