Overview Reference

Reference

Chrome and Edge driven through the DevTools Protocol for tests of pages, with the API of Playwright for what it has, and no dependencies. Every declaration of its TypeScript declarations (packages/browser/index.d.ts or index.d.cts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.

Functions

launch, findBrowser

launch

export declare function launch(options?: LaunchOptions): Promise<Browser>;

Starts Chrome or Edge in a profile of its own (removed when it closes).

findBrowser

export declare function findBrowser(): string | null;

The Chrome (or Chromium, or Edge) of this machine: CHROME, else where they install themselves; null when none.
