Overview Reference

Reference

A linter with ESLint's recommended rules (with their tests) and a formatter with prettier's output, on TypeScript's parser. Every declaration of its TypeScript declarations (packages/lint/index.d.ts or index.d.cts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.
