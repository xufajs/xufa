Overview Reference Playground

Reference

A fast HTTP router (a radix tree compiled to code, with a map of static routes), with the API of find-my-way and no dependencies. Every declaration of its TypeScript declarations (packages/router/index.d.ts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.
