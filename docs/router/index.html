@xufa/router

A fast HTTP router with the API of find-my-way, and no dependencies: a radix tree of routes, with static paths found in a map before the tree is walked. It is the router of @xufa/http, passes find-my-way's test suite, and works on its own with node:http or any server.

Quick start

npm install @xufa/router
const http = require('node:http');
const router = require('@xufa/router')({
  ignoreTrailingSlash: true,
  defaultRoute: (req, res) => { res.statusCode = 404; res.end('Not found'); },
});

router.get('/users/:id', (req, res, params, store, searchParams) => res.end(`user ${params.id}`));
router.on(['GET', 'HEAD'], '/files/*', (req, res, params) => res.end(params['*']));

http.createServer((req, res) => router.lookup(req, res)).listen(3000);

Static parts win over parameters, and parameters over wildcards. Regexps are checked for catastrophic backtracking when they are added (allowUnsafeRegex skips it). Parameters are decoded (%20), and longer than maxParamLength they do not match.

Handlers and stores

router.on('GET', '/admin/:page', { constraints: { host: 'admin.example.com' } }, handler, { auth: 'admin' });
router.get('/x', handler);   // and put, post, delete, head, patch, options, trace, connect, all
router.all('/health', ok);   // every method

on(method, path, [options], handler, [store]): the method can be a list; the store is any value, given back to the handler (and by find()). Handlers are called as handler(req, res, params, store, searchParams), with this the context given to lookup().

Finding a route

MethodWhat it does
lookup(req, res, [ctx])Finds the route of the request and calls its handler (or defaultRoute).
find(method, path, [constraints]){ handler, params, store, searchParams }, or null; the query string is parsed.
findRoute(method, path, [constraints])The route as it was added ('/users/:id'): its handler, store and parameter names.
hasRoute(method, path, [constraints])Whether that route was added.

Constraints

router.on('GET', '/api', { constraints: { version: '1.2.0' } }, v1);
router.on('GET', '/api', { constraints: { version: '2.0.0' } }, v2);
router.lookup(req, res); // Accept-Version: 2.x => v2

router.on('GET', '/', { constraints: { host: /.*\.example\.com/ } }, tenantHome);

// A strategy of your own:
const Router = require('@xufa/router');
const router2 = Router({
  constraints: {
    region: {
      name: 'region',
      storage: () => { const map = new Map(); return { get: (k) => map.get(k), set: (k, v) => map.set(k, v) }; },
      deriveConstraint: (req) => req.headers['x-region'],
      mustMatchWhenDerived: true,
    },
  },
});

version (semver ranges of Accept-Version) and host (strings or regexps) are there; routes with constraints win over the same route without them.

match()

What xufa calls for every request: it finds the route without calling its handler, and leaves the query string as it is, to be parsed only if it is read. The result has status (FOUND, BAD_URL or MAX_PARAM_LENGTH), handler, store, params and the unparsed querystring. The result object is reused: read it before the next call. 

const Router = require('@xufa/router');
const found = router.match('GET', '/users/7?full=true');
if (found !== null && found.status === Router.FOUND) found.handler(req, res, found.params, found.store);

Managing routes

router.off('GET', '/users/:id');           // removes a route (with constraints: those)
router.reset();                              // removes every route

Static paths are found with one lookup in a map, before the tree is walked. Once a tree has been walked a few times (Router.COMPILE_AFTER, 16), it is compiled into one function: each static part becomes comparisons of character codes, each parameter a slice, and backtracking falls through to the next child to try, with no call per node. match() leaves the query string to be parsed only if it is read; find(), which parses it as find-my-way's does, is from 1.06× to 2.16× find-my-way's.

Coming from find-my-way

  • The API and the behaviour are find-my-way's (its test suite passes); require('find-my-way') can be replaced by require('@xufa/router').
  • Added: match(), the map of static paths, the method QUERY, and the helpers.
