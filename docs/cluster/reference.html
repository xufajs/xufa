Overview Reference

Reference

An app in a cluster of processes, the messages between them, and pools of nodes shared by its workers, with no dependencies. Every declaration of its TypeScript declarations (packages/cluster/index.d.ts or index.d.cts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.

The fallback of use(): its node (or one made for each attempt), from which attempt, and how long to wait for a node.
