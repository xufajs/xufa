Reference

Safe JavaScript expressions compiled once and run many times on data, with no dependencies. Every declaration of its TypeScript declarations (packages/expression/index.d.ts or index.d.cts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.

EngineOptions

export interface EngineOptions { ... }
MemberType
globals?Record<string, unknown>

Names over the default globals (Math, JSON, Number...).

builtins?boolean

false: no default globals, only those given.

filters?Record<string, Filter> | null

Functions by name: | separates them in expressions (price | round(2), the value first).

lenient?boolean | 'members' | 'calls'

Members of null or undefined, and calls of what is not a function, give undefined (not errors); 'members' or 'calls': only those.

strict?boolean

Names that are not in the context nor the globals are errors (not undefined).

methods?Record<string, unknown> | null

Functions by name that values have as methods when they have none of that name: prices.sum() is methods.sum(prices) when prices.sum is undefined or null. An object or a module (what is not a function is left out); x['sum'](), x.sum?.() and null or undefined values are not looked up.

tdz?boolean

Programs: a let, const or class used before its declaration runs is an error (XUFA_EXPR_ERR_RUNTIME), as in JavaScript; by default it is undefined.

maxLength?number

The longest source compiled (10000).

cacheSize?number

How many expressions compiled are kept (1000; 0 for none).

inline?boolean

false: expressions stay closures (by default, those run often become one function of JavaScript).

inlineAfter?number

Runs before an expression becomes one function of JavaScript (64; 0: at once).

statements?boolean

Sources are programs: statements (let, const, if, for, for...of, while, switch, return, throw, try, functions), assignments of names and of members of plain objects and arrays, ++, --, delete, new and comments. Their value is that of their return, or of the last expression statement run.

scope?'program' | 'context'

Programs: 'program' (the default: the names a program declares or assigns are its own) or 'context' (those of its top level are the context's properties, as those of the global object of a script; this there is context.this). A program that writes the context needs a plain object.

onError?(error: unknown, details: { source: string; statement: number; context: Record<string, unknown> }) => void

Programs: an error of a top-level statement is given to it, the statement's value is undefined, and the program goes on with the next one. Limits (XUFA_EXPR_ERR_LIMIT) still end the run; syntax errors still throw.

maxSteps?number

The loop turns and calls of functions of a run of a program (10 million): past them, XUFA_EXPR_ERR_LIMIT.

maxDepth?number

How deep calls of a program's functions can nest (1000): deeper, XUFA_EXPR_ERR_LIMIT.

constructors?Record<string, new (...args: any[]) => unknown>

What new makes in programs, by name, over the default ones (Date, Map, Set, Error, TypeError, RangeError).

modules?ModuleResolver

What import of programs takes: the source of a module (a string: a program run for each import, with a context of its own) or what it exports (an object given by the host), or undefined (no such module).
