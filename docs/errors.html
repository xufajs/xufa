@xufa/errors

Classes of errors with a code, a status code and a message formatted with the arguments given, with the API of @fastify/error and no dependencies. The errors of xufa are made with it, so every error of the framework has a stable code to test for.

Quick start

npm install @xufa/errors
const createError = require('@xufa/errors');

const NotFound = createError('APP_NOT_FOUND', 'User %s not found', 404);

const err = new NotFound('ada'); // or NotFound('ada')
err.code; // 'APP_NOT_FOUND'
err.statusCode; // 404
err.message; // 'User ada not found'
err instanceof NotFound; // true
err instanceof createError.XufaError; // true, for every error made by createError

createError

createError(code, message, statusCode = 500, Base = Error, captureStackTrace = true):

ArgumentWhat it is
codeThe code of the errors (err.code) and their name.
messageA message formatted with util.format and the arguments of the error: %s, %d, %j, %o...
statusCodeerr.statusCode (500).
BaseThe class the errors extend: TypeError, RangeError, or a class of yours.
captureStackTracefalse: no stack trace (cheaper, for errors that are expected).

Using the classes

const Invalid = createError('APP_INVALID', 'Invalid %s: %j', 400, TypeError);

try {
  JSON.parse(body);
} catch (cause) {
  throw new Invalid('body', body.slice(0, 20), { cause }); // a last argument { cause } sets the cause
}

err instanceof TypeError; // true: Base
err.toString(); // 'XufaError [APP_INVALID]: Invalid body: "..."'

In HTTP responses

In @xufa/http, an error thrown by a handler is answered with its statusCode, and the JSON { statusCode, code, error, message }: 

app.get('/users/:id', async (request) => {
  const user = await findUser(request.params.id);
  if (!user) throw new NotFound(request.params.id);
  return user;
});
// 404 {"statusCode":404,"code":"APP_NOT_FOUND","error":"Not Found","message":"User 7 not found"}

Stack traces

A stack trace is most of the cost of an error. For errors that are part of normal work (a not found, a validation), captureStackTrace: false in createError skips it; createError.captureStackTrace = false makes that the default for the errors created after it.

The errors of xufa

Every error of xufa has its code: XUFA_ERR_* in @xufa/http (require('@xufa/http').errorCodes), BOOT_ERR_* in @xufa/boot, XUFA_ORM_ERR_* in the ORM, XUFA_AUTH_* in auth, XUFA_EXPR_ERR_* and XUFA_TEMPLATE_ERR_* in expressions and templates.

Coming from @fastify/error

  • The API is @fastify/error's; require('@fastify/error') can be replaced by require('@xufa/errors').
  • The class of every error is XufaError (FastifyError there), and so is their name.
  • Added: createError.captureStackTrace, the default of the last argument.

TypeScript

import createError, { XufaError, XufaErrorConstructor } from '@xufa/errors';

const NotFound: XufaErrorConstructor<{ code: 'APP_NOT_FOUND'; statusCode: 404 }, [string]> =
  createError('APP_NOT_FOUND', 'User %s not found', 404);
