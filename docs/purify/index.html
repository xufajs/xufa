Overview Reference

@xufa/purify

DOMPurify, the XSS sanitizer of HTML, on the DOM of @xufa/html: ready in Node with no jsdom. Its library is DOMPurify's (3.3.3, ported), so it removes what DOMPurify removes, and its tests pass on it. Ready in 48 ms with 6 MB of heap, where DOMPurify on jsdom took 760 ms and 28 MB; 7 to 13 times faster a call; and steady, where DOMPurify on jsdom slows down and grows as it works.

Quick start

npm install @xufa/purify
import DOMPurify from '@xufa/purify'; // or require('@xufa/purify')

console.log(DOMPurify.sanitize('<img src=x onerror=alert(1)><a href="javascript:alert(2)">Hi</a>'));
// Text only (no tags): what is shown in a page as text.
console.log(DOMPurify.sanitize('<p>Hi <b>there</b> & <script>x</script></p>', { ALLOWED_TAGS: [], KEEP_CONTENT: true }));
<img src="x"><a>Hi</a>
Hi there &amp;

Its API

DOMPurify's as it is: sanitize(dirty, config) with all its options (ALLOWED_TAGS, ALLOWED_ATTR, FORBID_TAGS, ADD_ATTR, USE_PROFILES, KEEP_CONTENT, WHOLE_DOCUMENT, RETURN_DOM, RETURN_DOM_FRAGMENT, SAFE_FOR_TEMPLATES, SANITIZE_NAMED_PROPS, PARSER_MEDIA_TYPE, NAMESPACE, IN_PLACE, ...), setConfig, clearConfig, isValidAttribute, hooks (addHook, removeHook), removed, and DOMPurify(window) for another window. The nodes it returns are of @xufa/html/dom. 

DOMPurify.addHook('afterSanitizeAttributes', (node) => {
  if (node.nodeName === 'A') node.setAttribute('rel', 'noopener');
});
console.log(DOMPurify.sanitize('<a href="https://example.com" onclick="x()">link</a>'));
DOMPurify.removeAllHooks();
const fragment = DOMPurify.sanitize('<b>bold</b><iframe></iframe>', { RETURN_DOM_FRAGMENT: true });
console.log(fragment.childNodes.length, fragment.firstChild.nodeName);
<a href="https://example.com" rel="noopener">link</a>
1 B

How it was checked

  • DOMPurify's own tests on it: 309 pass. Skipped: its tests that insert what it returns into a page and wait for alert() (no scripts run here), and its bootstrap tests (they load it by a <script>).
  • The same output as DOMPurify on jsdom 27 for its 216 XSS vectors with 12 configurations, and for 37,000 random markups. Where the two differed (text inside a <table>), DOMPurify in Chrome gives ours.
  • It runs on a DOM whose parser passes html5lib's conformance suite and that has the live NodeIterator, namespaces and attribute rules DOMPurify relies on: DOMPurify's README warns against DOMs that do not (happy-dom).
