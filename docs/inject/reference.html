Overview Reference

Reference

Fake HTTP requests to a Node.js request handler without a socket, with the API of light-my-request and no dependencies. Every declaration of its TypeScript declarations (packages/inject/index.d.ts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.
