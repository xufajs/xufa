Reference

Values as JSON that keeps classes (a registry), shared references, cycles, and Date, Map, Set, BigInt, Error, Buffer, undefined...; safe to parse from outside, with no dependencies. Every declaration of its TypeScript declarations (packages/marshal/index.d.ts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.

Interfaces

MarshalOptions, UnmarshalOptions, CloneOptions, ClassOptions

MarshalOptions

export interface MarshalOptions { ... }
MemberType
registry?Registry

The classes whose instances come back as themselves (the default registry when not given).

maxDepth?number

Deeper values are a MarshalError (1000).

unknown?'object' | 'error'

Instances of classes not registered: their fields as a plain object ('object', the default), or an error.

functions?'throw' | 'skip'

A function as a value: an error ('throw', the default), or left out ('skip').

stack?boolean

The stack of errors is written (true).
