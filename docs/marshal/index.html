@xufa/marshal

Values as JSON that keeps what JSON loses: the classes of your objects (through a registry), objects referenced twice, cycles, and undefined, NaN, -0, BigInt, Date, RegExp, Map, Set, Buffer, errors and more. It is safe to parse what comes from outside, and has no dependencies.

Quick start

npm install @xufa/marshal
import { stringify, parse, clone, registry } from '@xufa/marshal';

class Point {
  constructor(x, y) {
    this.x = x;
    this.y = y;
  }
  norm() {
    return Math.hypot(this.x, this.y);
  }
}
registry.register(Point);

const shared = { n: 1 };
const back = parse(stringify({ at: new Date(0), point: new Point(3, 4), big: 10n, a: shared, b: shared }));
console.log(back.point.norm()); // 5: a Point again
console.log(back.a === back.b); // true: one object, as it was
console.log(back.at.toISOString(), typeof back.big);

const copy = clone(back); // a deep copy that keeps classes, references and cycles
console.log(copy.point instanceof Point, copy.a === copy.b);

Classes

registry.register(Point) (or register(A, B, C)) makes the instances of a class come back as themselves: their own enumerable fields are written, and an instance is made again from the prototype of the class, without calling its constructor. A class with state outside its fields (private #fields, a handle) says how it is written: 

import { ENCODE, DECODE } from '@xufa/marshal';

class Money {
  #cents;
  constructor(cents, currency) {
    this.#cents = cents;
    this.currency = currency;
  }
  static [ENCODE](money) {
    return [money.#cents, money.currency];
  }
  static [DECODE]([cents, currency]) {
    return new Money(cents, currency);
  }
}
registry.register(Money); // or register(Money, { name: 'money', encode, decode })

Classes are known by name (Class.name, or { name } when two share one). Errors of registered classes come back as their class, with message, stack, cause and their fields. new Registry(), passed as { registry }, keeps apart the classes of different parts of an app.

What it keeps

Everything JSON keeps, and: undefined (in objects and arrays), holes, NaN, the infinities, -0, BigInt, global symbols, Date (invalid ones too), RegExp (source and flags), Map and Set (any keys), Buffer, every typed array, ArrayBuffer, DataView, Error and its built-in kinds and AggregateError (message, stack, cause, fields), URL, URLSearchParams, boxed primitives, objects without prototype, the instances of registered classes, objects referenced twice and cycles. Functions, local symbols, promises and weak collections are an error, as in structuredClone.

The format

The value as JSON writes it, with what JSON cannot say written so that JSON.parse makes as few objects as it can: stringify({ a: shared, b: shared, at: new Date(0), tags: ['x'] }) is {"a":{"n":2},"b":"¤R1","at":"¤D0","tags":["x"]}, and an instance of a registered class is {"@":"Point","x":1,"y":2}.

  • Marked strings (starting with ¤): "¤D" + ms (a Date), "¤R" + n (the object numbered n, in the order they are written: shared objects and cycles), "¤B" + digits (BigInt), "¤u" (undefined), "¤h" (a hole), "¤N", "¤I", "¤i", "¤z" (NaN, ±Infinity, -0).
  • An array of plain objects, or of instances of one registered class, all with the same fields, is a table: ["¤Table", "Point", ["x", "y"], 1, 2, 3, 4] (null for plain objects), the keys written once and no copy of each row made. The rows of a database, the common case, are read and written about twice as fast so.
  • Tagged arrays, whose first item is a marked string: ["¤Map", k, v, ...], ["¤Set", ...], ["¤RegExp", source, flags], ["¤Error", ...], ["¤@Money", data, 1] (written by the class's encode())...
  • Data that would look like them is escaped: a string starting with ¤ is "¤S" + the string, an object with a field "@" is ["¤Object", {...}], and an array whose first item is written marked is ["¤Array", ...items]. Nothing of the data is ever taken for something else.
  • Long strings (64 characters or more) are written once, and then as references.

Input from outside

parse() looks up no constructor or global by a name of the input (only the registered classes and a fixed list of built-ins), calls no constructor, defines the fields of instances (no setter of a class runs), takes "__proto__" as a field like any other, and has limits of depth and size. Malformed input is always a MarshalError. Its tests include the problems of the serializer it replaces (a string taken for a reference, a function made from the input, the prototype set by the input) and 2,000 random values compared with structuredClone.

With xufa

  • @xufa/cluster: start({ marshal: registry }): the messages of the bus keep their classes, and errors thrown by the handlers of requests arrive as their class.
  • @xufa/netcache: new NetCache({ marshal: registry }): cached values keep their classes on every machine.

Performance

stringify and parse, operations a second, best of 5 rounds (node bench/micro/marshal.js, bench/results/marshal-4.md). JSON loses the Dates, Maps and classes; v8.serialize writes binary (the IPC of node:cluster) and loses the classes. The format of bench/results/marshal-1.md (a flat list of nodes, every number and string a node of its own) was 0.5x to 0.75x of v8.serialize; this one is 1.2x to 1.6x of it on rows of a database, 2x on class instances, 2.4x on small objects, and about even on Maps and Sets. On Linux (bench/results/marshal-linux-5.md): 1.1x on rows, 1.8x on instances, 2x on small objects, 1x on Maps and Sets.
