Overview Reference

Reference

Excel workbooks (.xlsx) read into values and written from them (styles, merged cells, widths), and cells patched in place keeping the rest, with no dependencies. Every declaration of its TypeScript declarations (packages/xlsx/index.d.ts or index.d.cts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.

Functions

readXlsx, writeXlsx, patchXlsx, cellAt, columnName, refOf, excelDate, unzip, zip

readXlsx

export function readXlsx(bytes: Uint8Array): { sheets: Required<Sheet>[] };

The sheets of the bytes of a .xlsx.

writeXlsx

export function writeXlsx(workbook: { sheets: WritableSheet[] }): Buffer;

The bytes of a .xlsx of these sheets.

patchXlsx

export function patchXlsx(
  bytes: Uint8Array,
  sheetName: string,
  values: Record<string, CellValue> | Map<string, CellValue>,
  options?: { whole?: Record<string, CellValue> | Map<string, CellValue> }
): Buffer;

The bytes of a .xlsx with some cells of one sheet set ({ C7: 0.5 } or a Map), nothing else of it changed (styles, other sheets, comments are kept). Merged ranges whose cells get different values are split; whole: the values of the whole area the cells are of (a table's matrix), which tells which merges are cut.
