Overview Reference

Reference

Faults made to happen (fail, delay, hang, down), to test what an app does when what it uses fails: the rules of the faults of the ORM, the HTTP client, the caches and the bus of xufa. No dependencies. Every declaration of its TypeScript declarations (packages/faults/index.d.ts or index.d.cts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.
