Overview Reference

@xufa/websocket

WebSockets for Node.js, with no dependencies: the client and server of ws (RFC 6455, permessage-deflate), WebSocket routes for @xufa/http (and fastify), and rooms of sockets that reach every worker of a cluster and every machine.

Quick start

npm install @xufa/websocket
import xufa from 'xufa';
import websocketPlugin from '@xufa/websocket/plugin';

const app = xufa();
app.register(websocketPlugin);

app.get('/chat', { websocket: true }, (socket, request) => {
  socket.on('message', (message) => socket.send(`echo: ${message}`));
});

await app.listen({ port: 3000 });

WebSocket routes

The upgrade of a request goes through the routing like any request: its hooks run first (authentication, rate limits, a preValidation that answers 401), and only then is the socket handed to the route. request.ws says whether a request is an upgrade.

Option of the pluginWhat it does
optionsThe options of the server of ws: maxPayload, perMessageDeflate, verifyClient...
errorHandler(error, socket, request, reply)Errors of handlers and of open sockets (the default logs and terminates).
preCloseWhat closing the app does with the sockets (the default closes them).

wsHandler in the options of a route answers its upgrades while handler answers HTTP; app.websocketServer is the server of ws; app.injectWS('/chat') opens a socket to a route in tests, without a network. The behavior is the one of @fastify/websocket.

Rooms everywhere

import { Hub } from '@xufa/websocket/hub';

const hub = new Hub({ bus, cache }); // the bus of @xufa/cluster, a NetCache of @xufa/netcache: as there are

app.get('/chat', { websocket: true }, (socket, request) => {
  hub.add(socket, { rooms: ['lobby', `user:${request.user.id}`] }); // until it closes
  socket.on('message', (text) => hub.to('lobby').except(socket).send({ from: request.user.id, text: String(text) }));
});

hub.to('user:42').send({ notice: 'You have mail' }); // every socket of user 42, in any worker of any machine

A message is serialized once where it is sent (strings and bytes as they are, other values as JSON), and every process sends it to its sockets of the rooms. In a cluster, the primary has a hub too: it relays what a worker sends to the other workers and, with a NetCache, to the other machines (through its pub/sub: the machines connected at that moment), and what comes from other machines to every worker.

MethodWhat it does
add(socket, { rooms })A socket in the hub (and its rooms), until it closes: its id.
join(socket, ...rooms), leave(socket, ...rooms), roomsOf(socket)The rooms of a socket.
to(...rooms).except(...sockets).send(data)The sockets of those rooms, in every process and machine (except: sockets, or ids of sockets of other processes).
send(data)Every socket.
local(room)The ids of the sockets of this process in a room.

The client and server of ws

import { WebSocket, WebSocketServer } from '@xufa/websocket';

const wss = new WebSocketServer({ port: 8080, perMessageDeflate: true });
wss.on('connection', (socket) => socket.on('message', (data) => socket.send(data)));

const ws = new WebSocket('ws://localhost:8080');
ws.on('open', () => ws.send('hello'));

Coming from ws

  • ws can be replaced by @xufa/websocket (in imports or requires), and import { WebSocketServer } from 'ws' by from '@xufa/websocket': the code is the one of ws 8.22.0.
  • For Node.js 22 and later: UTF-8 is validated by buffer.isUtf8, native, so utf-8-validate is left out. bufferutil is used as ws uses it: when the application has installed it (npm i bufferutil), unless WS_NO_BUFFER_UTIL is set. It is not a dependency; without it, frames are masked 8 bytes at a time in JavaScript.
  • @fastify/websocket can be replaced by @xufa/websocket/plugin (in imports or requires), on @xufa/http or fastify.

Tests

The suites of ws (438 tests) and @fastify/websocket (62, run on @xufa/http) are ported to vyntra by tools/port-ws from checkouts of their repositories. The tests of the hub run it in one process, between two machines (two NetCaches) and in a cluster of two workers.

TypeScript

The declarations of ws (@types/ws), of @fastify/websocket for @xufa/http (@xufa/websocket/plugin: { websocket: true } routes, request.ws, app.websocketServer) and of the hub.
