Reference

JSON serializers compiled from JSON Schema, with the output of fast-json-stringify and no dependencies. Every declaration of its TypeScript declarations (packages/serializer/index.d.ts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.

Options

export interface Options { ... }
MemberType

Optionally add an external definition to reference from your schema

ajv?AjvOptions

Configure Ajv, which is used to evaluate conditional schemas and combined (anyOf) schemas

Optionally configure how the integer will be rounded

  • Default: 'trunc'
mode?'debug'

Running mode of fast-json-stringify

output?'auto' | 'string' | 'bytes'

How the JSON is made: joined as a string (fastest for values of a size the schema knows), or written as bytes (fastest for arrays and maps). 'auto' picks by the schema.

  • Default: 'auto'
largeArraySize?number | string | BigInt

Large arrays are defined as arrays containing, by default, 20000 elements or more. That value can be adjusted via the option parameter largeArraySize.

  • Default: 20000
largeArrayMechanism?'default' | 'json-stringify'

Specify the function on how large Arrays should be stringified.

  • Default: 'default'
