Overview Reference

Reference

Messages in the languages of an app: catalogs, plurals by the rules of each language, fallbacks, the locale of each request (Accept-Language, cookie, query) in its async context, and the messages users read of @xufa/orm, @xufa/auth and @xufa/admin translated, with no dependencies. Every declaration of its TypeScript declarations (packages/i18n/index.d.ts or index.d.cts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.
