Overview Reference

Reference

A client of HTTP APIs on the fetch of Node.js, with no dependencies: base URLs, JSON, timeouts, retries with backoff, errors by status, hooks, logs, and the cancellation of the request that calls. Every declaration of its TypeScript declarations (packages/client/index.d.ts or index.d.cts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.

ClientOptions

export interface ClientOptions { ... }
MemberType
baseUrl?string

The URL paths are joined to (its path kept: '/v1' + '/books').

headers?Record<string, string | number | undefined | null>
query?Record<string, unknown> | URLSearchParams

Query string: arrays repeat the key, dates are ISO, undefined and null are left out.

timeout?number

ms for each attempt (30000; 0: none).

retry?RetryOptions | number | false

Retries: the number of attempts, false, or the options.

responseType?'auto' | 'json' | 'text' | 'buffer' | 'stream' | 'response'

How the answer is read: auto (JSON by its type, text otherwise), json, text, buffer, stream (a web ReadableStream, decompressed, read as it comes), or the Response of fetch.

resolveBodyOnly?boolean

false: { status, headers, body, url } instead of the body.

throwHttpErrors?boolean

false: error statuses are answers, not HTTPErrors.

requestIdHeader?string | null

The header of the id of the request a client is bound to (x-request-id); null: not sent.

hooks?{ beforeRequest?: ((call: Call) => void | Promise<void>) | Array<(call: Call) => void | Promise<void>>; afterResponse?: | ((response: Response, call: Call) => void | Promise<void>) | Array<(response: Response, call: Call) => void | Promise<void>>; }
log?Logger | null

Where requests, answers and retries are logged (debug); the log of the bound request by default.

request?BoundRequest | null

The request it is bound to: its signal, log and id.

signal?AbortSignal | null
dispatcher?unknown

A dispatcher of undici (proxies, pools): given to fetch.

redirect?'follow' | 'error' | 'manual'
transport?'fetch' | 'http'

'http' (the default): the calls over node:http and node:https, faster, compressed answers decompressed; Response answers and a dispatcher go through fetch. 'fetch': every call.

proxy?string | URL | 'env' | false

The proxy of the http transport: a URL (http: or https:, with user:password to log in), 'env' (HTTP_PROXY, HTTPS_PROXY, NO_PROXY), or false. By default, that of the environment when NODE_USE_ENV_PROXY is set (as Node.js). https: servers are reached through tunnels (CONNECT), kept alive.

tls?import('node:tls').ConnectionOptions

Options of TLS of the http transport (its https: servers and proxies): ca, cert and key, rejectUnauthorized...
