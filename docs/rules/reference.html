Overview Reference

Reference

Business rules in Excel workbooks (decision tables, spreadsheets, tests) run as functions, with safe compiled expressions. Every declaration of its TypeScript declarations (packages/rules/index.d.ts or index.d.cts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.
