Overview Guide Reference

Reference

Authentication with no dependencies: scrypt passwords, JSON Web Tokens with rotating keys, TOTP, login lockout, rotating refresh tokens, API keys, HTTP Basic, Passport strategies and a plugin for @xufa/http. Every declaration of its TypeScript declarations (packages/auth/index.d.ts or index.d.cts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.
