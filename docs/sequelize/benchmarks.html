Benchmarks

The same Sequelize code on @xufa/sequelize and on Sequelize 6 as it installs (pg, sqlite3), with the ORM's own API next to them, on the same models, data and machine. Each library runs every round in a process of its own; the median of the rounds is shown, with how many times Sequelize's it is (⚠: rounds more than 10% apart).

Where the database does the work (an update of thousands of rows, a sort of a big table), the libraries are about even: the time is the database's. Where the library does the work (building queries, making objects, the round trips of the driver), xufa is from 2 to 18 times faster. @xufa/sequelize is faster than the ORM's own API at findByPk: it reads one row, where the ORM's get() asks for a few to make sure only one matches (as Django does).

Run them yourself

node bench/orm.js --orms xufa-sequelize,sequelize        # the same Sequelize code, on each
node bench/orm.js --orms xufa-sequelize,sequelize,sequelize-xufa-pg --dialects postgres

sequelize-xufa-pg is Sequelize on @xufa/pg: what the driver alone gives. The tables are bench_author and bench_book, dropped before and after.
