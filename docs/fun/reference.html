Overview Reference

Reference

A functional library of curried functions on any value (lists, strings, objects, iterables), with placeholders and operators classes take part in, with no dependencies. Every declaration of its TypeScript declarations (packages/fun/index.d.ts or index.d.cts), as they are written, with their comments: made from them each time the docs are built. How to use them is in the overview.
