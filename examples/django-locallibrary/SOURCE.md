# Source

This folder is the Django project that `examples/locallibrary` ports to xufa, copied as it is (without `.git` and
`.github`) from:

- Repository: https://github.com/mdn/django-locallibrary-tutorial
- Commit: fc264f344ce2d5bf1e927328f7f0687bde74f48b (2026-10-05)
- License: CC0 1.0 Universal (see `LICENSE`)

It is the LocalLibrary of the MDN Django tutorial: a catalog of books, authors, genres, languages and copies of books
that users borrow, with the admin, logins and permissions, forms, generic views, sessions and tests.
