Benchmarks

Operations or rows a second of @xufa/orm, of Sequelize 6 as it installs (pg, sqlite3), and of the same Sequelize code on @xufa/sequelize, on the same models, data and machine. Where the database does the work, they are about even; where the library does it, the ORM is faster.

How they are measured

Every library runs every round in a process of its own, the libraries taking turns, and the median of the rounds is shown, with how many times Sequelize's it is. ⚠ marks a result whose rounds are more than 10% apart: the machine was busy, so read it as a range. PostgreSQL runs on the same machine, with a pool of 10 connections for each library.

Run them yourself

node bench/orm.js                                   # PostgreSQL and SQLite, every workload
node bench/orm.js --dialects sqlite --rounds 3      # SQLite only
node bench/orm.js --only "findByPk (serial),count where" --url postgres://user:password@localhost:5432/bench

It uses the tables bench_author and bench_book, dropped before and after. The stacks (--orms) are xufa, sequelize, sequelize-xufa-pg (Sequelize on @xufa/pg: what the driver alone gives) and xufa-sequelize.

Its drivers

The ORM reaches PostgreSQL and MongoDB with drivers of its own: @xufa/pg against pg and @xufa/mongo against the official driver.
