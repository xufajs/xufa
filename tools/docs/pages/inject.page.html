@xufa/inject

Fake HTTP requests to a Node.js request handler, without a socket: the handler gets a real IncomingMessage and ServerResponse, and you get the response. It has the API of light-my-request and passes its test suite, has no dependencies, and is app.inject() of @xufa/http: tests run in the process, in microseconds, without ports.

Quick start

npm install @xufa/inject
import inject from '@xufa/inject';

const handler = (req, res) => {
  res.writeHead(200, { 'content-type': 'text/plain' });
  res.end(`${req.method} ${req.url}`);
};

const res = await inject(handler, { method: 'POST', url: '/items?x=1', payload: { a: 1 } });
res.statusCode; // 200
res.payload; // 'POST /items?x=1'

Any (req, res) handler: node:http, Express, Koa's app.callback()...

In xufa

import app from './app.js'; // a xufa app, not listening

test('creates a user', async () => {
  const res = await app.inject({ method: 'POST', url: '/users', payload: { name: 'Ada' } });
  expect(res.statusCode).toBe(201);
  expect(res.json()).toMatchObject({ name: 'Ada' });
});

app.inject() waits for the app to be ready (its plugins loaded) before the request.

Options of a request

OptionWhat it is
url (or path)A string, or { pathname, protocol, hostname, port, query }.
methodGET by default.
headersThe headers of the request.
queryA string or an object, added to the query of the URL.
payload (or body)A string, a Buffer, an object (sent as JSON) or a stream.
cookiesCookies by name.
remoteAddress, authorityThe address of the client (127.0.0.1), the host.
signalAn AbortSignal that aborts the request.
simulateSee Simulating failures.
serverThe server the request comes to (req.socket.server).
payloadAsStreamThe response is given as a stream, not read whole.
validatefalse skips the checks of the options.

The options can be a string, the URL of a GET.

The response

MemberWhat it is
statusCode, statusMessageThe status.
headers, trailersThe headers and trailers sent.
payload (or body)The body, as text.
rawPayloadThe body, as a Buffer.
json()The body, parsed.
stream()The body, as a readable stream.
cookiesThe cookies set: { name, value, expires, maxAge, secure, httpOnly, sameSite, path, domain }.
raw.req, raw.resThe request and response objects the handler got.

Chained requests

const res = await inject(handler)
  .post('/login')
  .headers({ 'x-tenant': 'acme' })
  .cookies({ session: 's1' })
  .query({ next: '/home' })
  .body({ user: 'ada', password: 'secret' })
  .end();

get, post, put, patch, delete, head, options, trace, then headers, query, cookies, body (or payload); end() sends it (or await the chain).

Payloads

await inject(handler, { method: 'POST', url: '/upload', payload: fs.createReadStream('photo.jpg'),
  headers: { 'content-type': 'image/jpeg' } });
await inject(handler, { method: 'POST', url: '/form', payload: 'a=1&b=2',
  headers: { 'content-type': 'application/x-www-form-urlencoded' } });

Objects are sent as JSON with content-type: application/json; content-length is set for strings and Buffers.

Simulating failures

await inject(handler, { method: 'POST', url: '/', payload: 'data', simulate: { split: true } }); // two chunks
await inject(handler, { method: 'POST', url: '/', payload: 'data', simulate: { close: true } }); // the client goes away
await inject(handler, { method: 'POST', url: '/', payload: 'data', simulate: { error: true } }); // the request errors
await inject(handler, { method: 'POST', url: '/', payload: 'data', simulate: { end: false } }); // never ends

isInjection

inject.isInjection(req) (or of the response) tells whether a request came from inject.

Coming from light-my-request

The API is light-my-request's, and so are its tests; light-my-request can be replaced by @xufa/inject (in imports or requires).
