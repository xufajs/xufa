@xufa/fun

A functional library of plain functions that work on any value: lists, strings, objects, iterables, or one item. They are curried, _ holds an argument's place, paths read and write deep values, and classes can take part in the operators. It has no dependencies, and is made to be the methods of expressions too: prices.sum().

Quick start

npm install @xufa/fun
import { getAtPath, map, sum, subtract, median, _ } from '@xufa/fun';

const order = { lines: [{ price: 4 }, { price: 6 }], customer: { name: 'Ann' } };
console.log(getAtPath(order, 'customer.name'), getAtPath(order, 'lines[1].price'));
console.log(sum(map(order.lines, (line) => line.price)));
console.log(median([7, 1, 3]), subtract(_, 1)(10));

Any value

The functions walk what they are given: arrays and array-likes and strings by index, iterables (Set, Map, generators) in order, objects by key, and anything else as one item; null and undefined have no items. map, filter and reduce give arrays; their *Src forms give what the source is: a string of a string, an object of an object, a typed array of a typed array. 

import { map, mapSrc, filterSrc, len, reduce } from '@xufa/fun';

console.log(map({ a: 1, b: 2 }, (n, key) => `${key}${n}`));
console.log(mapSrc('abc', (c) => c.toUpperCase()), filterSrc({ a: 1, b: 2 }, (n) => n > 1));
console.log(len(new Set([1, 2])), len({ x: 1 }), len('four'));
console.log(reduce(new Map([['a', 1]]), (acc, [key, value]) => `${acc}${key}=${value}`, ''));
[ 'a1', 'b2' ]
ABC { b: 2 }
2 1 4
a=1

Currying

Given fewer arguments than they take, the functions give a function of the rest; _ holds the place of one given later. curry and curryN make functions of yours so. 

import { clamp, subtract, curry, _ } from '@xufa/fun';

const percent = clamp(0, 100);
console.log(percent(140), percent(-3), subtract(_, 5)(12));
const line = curry((qty, price, tax) => qty * price * (1 + tax));
console.log(line(2)(10)(0.5), line(2, _, 0.5)(10));
100 0 7
30 30

Paths

getAtPath(value, 'a.b[0].c') reads (undefined when a step has nothing), setAtPath sets on a copy and setAtPathMut on the object itself, making the objects and arrays on the way. getAt and setAt take an index from the end too: getAt(list, -1). 

import { getAtPath, setAtPath, setAtPathMut, getAt } from '@xufa/fun';

const doc = { a: { b: [10, 20] } };
console.log(getAtPath(doc, 'a.b[1]'), getAtPath(doc, 'a.x.y'), getAt(doc.a.b, -1));
console.log(setAtPath(doc, 'a.b[0]', 1).a.b, doc.a.b);
console.log(setAtPathMut({}, 'x[0].y', 2));
20 undefined 20
[ 1, 20 ] [ 10, 20 ]
{ x: [ { y: 2 } ] }

Operators

add, subtract, mult, div, mod and pow take any number of values. add merges objects, adds lists item by item, and adds strings and numbers as JavaScript does; the others take numbers. A class takes part with a static method named by a tag (ADD_TAG, MULT_TAG, NEGATE_TAG...). 

import { add, mult, ADD_TAG } from '@xufa/fun';

class Money {
  constructor(cents) {
    this.cents = cents;
  }
  static [ADD_TAG](a, b) {
    return new Money(a.cents + (b.cents ?? b));
  }
}
console.log(add(1, 2, 3), add([1, 2], [10, 20]), add({ a: 1 }, { b: 2 }), mult('2', 3));
console.log(add(new Money(250), new Money(100)).cents);
6 [ 11, 22 ] { a: 1, b: 2 } 6
350

In expressions

Given to an engine of @xufa/expression as its methods, the functions are methods of every value that has none of their name: prices.sum() is sum(prices). Users write formulas as they think of them, and the values stay plain data. 

import { Engine } from '@xufa/expression';
import * as fun from '@xufa/fun';

const engine = new Engine({ methods: fun });
const context = { prices: [4, 9, 2], order: { customer: { name: 'Ann' } } };
console.log(engine.evaluate('prices.sum() / prices.len()', context));
console.log(engine.evaluate("order.getAtPath('customer.name')", context), engine.evaluate('prices.median()', context));
5
Ann 4

The functions

  • Walking: forEach, forEachRight, forWhile (until false), map, mapRight, mapSrc, mapRightSrc, filter, filterSrc, reduce, reduceRight, every, some, none.
  • Lists: concat, zip, zipObj, zipWith, fromPairs, allowIndexes, denyIndexes (and their *Src), range, len, asArrayLike, boolDict.
  • Paths: getAt, getAtPath, setAt, setAtPath, setAtPathMut, atPath, atIndex.
  • Numbers: add, subtract, mult, div, mod, pow (and their *Op of two), inc, dec, negate, sum, mean, median, max, min, clamp, gt, gte, lt, lte.
  • Logic: and, or, not, andOp, orOp, andFn, orFn (of functions, for the same arguments).
  • Functions and values: curry, curryN, curry2, curry3, _, isPlaceholder, pipe, always, identity, merge (deep, on a copy), approve, and the tests isArray, isArrayLike, isObject, isString, isFunction, isIterable, isInteger, isNull, isPromise, has.
