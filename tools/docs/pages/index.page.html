Framework for Node.js

The parts of a web app, in the spirit of Django, with no dependencies.

xufa is an HTTP framework with the API of fastify, a Django-like ORM that runs the same models on SQLite, PostgreSQL and MongoDB, the API of Sequelize 6 on top of it, and the database drivers they need. Every part is written from scratch and works on its own, and none of them installs a dependency.

Get started Try it in your browser Move from Sequelize 
import xufa from 'xufa';

const app = xufa({ logger: true });

app.get(
  '/users/:id',
  {
    schema: {
      params: { type: 'object', properties: { id: { type: 'integer' } } },
      response: {
        200: {
          type: 'object',
          properties: { id: { type: 'integer' }, name: { type: 'string' } },
        },
      },
    },
  },
  async (request) => ({ id: request.params.id, name: 'Ada' })
);

await app.listen({ port: 3000 });
import { Database, Model, fields, Count } from 'xufa/orm';

class Author extends Model {
  static fields = { name: fields.string({ maxLength: 100 }) };
}

class Book extends Model {
  static fields = {
    title: fields.string(),
    pages: fields.integer({ null: true }),
    author: fields.foreignKey(() => Author, { relatedName: 'books' }),
  };
}

const db = new Database({ backend: 'postgres', url: process.env.DATABASE_URL });
db.register(Author, Book);
await db.connect();

const long = await Book.objects
  .filter({ author__name__istartswith: 'a', pages__gte: 300 })
  .selectRelated('author')
  .orderBy('-pages');
await Author.objects.values('name').annotate({ books: Count('books') });
// 'sequelize', changed: the rest of the code as it was.
import { Sequelize, DataTypes, Op } from '@xufa/sequelize';

const sequelize = new Sequelize(process.env.DATABASE_URL);
const Author = sequelize.define('Author', { name: DataTypes.STRING });
const Book = sequelize.define('Book', { title: DataTypes.STRING, pages: DataTypes.INTEGER });
Book.belongsTo(Author, { as: 'author' });

await sequelize.sync();
const books = await Book.findAll({
  where: { pages: { [Op.gte]: 300 } },
  include: [{ model: Author, as: 'author' }],
  order: [['pages', 'DESC']],
});

Faster where it counts

The same workloads, the same database, the same machine. The ORM against Sequelize 6, and the drivers against the ones they replace. See Benchmarks for every number and how they were measured.

2.9×faster than Sequelize 6 finding rows by key on PostgreSQL (12.3× on SQLite)
2.5×faster creating rows, the same Sequelize code run on @xufa/sequelize
4.7×faster than pg with 64 queries at once (@xufa/pg)
4.3×faster than the official MongoDB driver with 64 reads at once (@xufa/mongo)

What it is made of

Each part is a package of its own, usable alone. Where an existing library has the right API, xufa keeps it: code written for fastify, Sequelize, pg or pino runs on xufa's part, and their test suites are its tests.

No dependencies

Installing xufa installs xufa. The HTTP layer, its router, logger and serializer, the ORM, the PostgreSQL and MongoDB drivers, the validator: all of it is in this repository.

fastify's API, and its tests

Routes, hooks, plugins and encapsulation, decorators, schemas, inject() and the TypeScript types are fastify's. Its test suite, ported, is xufa's: 2,248 tests.

A Django-like ORM

Models, QuerySets, lookups (author__name__icontains), Q and F, aggregates, relations and migrations, the same on SQLite, PostgreSQL, MongoDB and memory.

Sequelize code, unchanged

@xufa/sequelize is the API of Sequelize 6 on the ORM: models, associations, includes, scopes, hooks, transactions. Sequelize's own integration tests run against it.

Its own drivers

@xufa/pg has pg's API, prepares queries, reads binary results and pipelines; @xufa/mongo has the official driver's, with replica sets, transactions and compression.

For real applications

Several databases at once, a database per tenant, caches of models shared through a cluster of processes, PostgreSQL arrays, hstore and PostGIS geometries.
