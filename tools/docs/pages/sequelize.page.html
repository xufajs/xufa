Sequelize

@xufa/sequelize is the API of Sequelize 6 over xufa's ORM. Code written for Sequelize runs with @xufa/sequelize instead of sequelize in its imports (or requires): faster, and with no dependencies.

The same code

import { Sequelize, DataTypes, Op } from '@xufa/sequelize'; // was: from 'sequelize'

const sequelize = new Sequelize('sqlite::memory:', { logging: false }); // or 'postgres://...'

const Author = sequelize.define('Author', { name: { type: DataTypes.STRING, allowNull: false } });
const Book = sequelize.define('Book', {
  title: DataTypes.STRING,
  pages: { type: DataTypes.INTEGER, validate: { min: 1 } },
});
Author.hasMany(Book, { as: 'books' });
Book.belongsTo(Author);
await sequelize.sync();

const ada = await Author.create({ name: 'Ada' });
await Book.bulkCreate([
  { title: 'Notes', pages: 120, AuthorId: ada.id },
  { title: 'Letters', pages: 80, AuthorId: ada.id },
]);

const long = await Book.findAll({ where: { pages: { [Op.gte]: 100 } }, include: Author });
console.log(long.map((book) => `${book.title} by ${book.Author.name}`));
const withBooks = await Author.findOne({ where: { name: 'Ada' }, include: { model: Book, as: 'books' } });
console.log(withBooks.books.map((book) => book.title).sort());
console.log(await Book.count({ where: { title: { [Op.like]: 'N%' } } }));
try {
  await Book.create({ title: 'Empty', pages: 0 });
} catch (err) {
  console.log(err.name, err.errors.map((e) => e.message)); // as Sequelize gives them
}
await sequelize.close();

Why @xufa/sequelize

  • Speed without a rewrite. The same models and queries, from 2 to 18 times faster where the library does the work (Benchmarks).
  • No dependencies. PostgreSQL through @xufa/pg, SQLite through node:sqlite: nothing to compile, nothing to audit.
  • A way into the ORM. The models are models of @xufa/orm: new code can use its QuerySets, resources and tenants, next to the Sequelize code that is there.
