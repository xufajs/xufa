Schema from JSON

Paste one or more JSON samples: @xufa/schema writes the schema that accepts all of them. Everything runs in your browser.

How it reads the samples: a key is required when every sample has it, a value seen as null is nullable, the elements of arrays are merged, and strings get a format (date-time, email, uuid...) when all of them match it. More samples give a more accurate schema.
